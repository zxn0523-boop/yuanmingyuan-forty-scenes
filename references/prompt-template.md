# 提示词模板

```text
Use case: style-transfer / historical-scene
Asset type: 古建筑园林复原效果图

输入图片角色：
- 图 1：编辑目标与最高优先级几何依据；可同时包含大面积半透明地形色块。保留建筑布局、相机视角和遮挡关系，只把连续大片平涂色域视为标注，忽略建筑本身的红柱、青绿彩画等细小颜色。
- 图 2（如有）：与图 1 同视角的线稿；用于锁定屋脊、墙线、廊道和亭台轮廓。
- 独立语义图（如有）：默认绿色为平地/一般陆地，红色为山体/隆起地形，蓝色为水体，黄色兼容为未细分地形。绿色与红色共同构成陆地范围。色块控制大致范围、相对位置和高低趋势，不要求最终边界逐像素吻合；最终删除全部色块、图例和标注字。
- 后续 2–3 图：来自《圆明园四十景图》原作画页的互补风格参考，分别约束总体山水格局、建筑界画和水岸/林木细节。只借鉴共通的画面语言，不复制任何具体建筑、地形、御题诗、收藏印、锦边或文字。

主要请求：把 SU 场景转成《圆明园四十景图》式清代宫廷界画设色山水。以建筑复原准确性为第一优先级，在标注或空白区域补全连贯园林环境。

当前场景结构清单：<逐项填写建筑组数量、相对方位、屋顶形制、亭台、廊墙、前后层级与不可遮挡立面>

构图：保持原图画幅和高位斜俯视视角；建筑位置、朝向、比例层级与相互距离不变。采用原作式散点空间和近、中、远三层结构。山体、平地和水体严格服从语义标注；没有蓝色水体或用户说明时不得增加水。保留空濛区域，不要填满所有空白。
风格与材质：清代宫廷界画细线设色。浅米黄旧绢底与细密经纬纹；深褐黑但不机械均匀的建筑线；密集平行瓦线；温灰白墙、灰青瓦、少量朱红和克制石青石绿。山体圆浑层叠，以短密皴线加灰绿、橄榄绿和赭石淡染；远山淡青灰。水面基本保留绢底，只用极淡灰青与少量水平细纹。树冠以密集细点和短线组成，树干纤细分叉，少量粉白花树。光线均匀、几乎无投影。

真实性要求：结果应像一幅保存状态良好的十八世纪清宫设色绢本画心扫描，而不是现代数字国风插画。建筑与山水必须共享相同线质、纸绢底色、综合色阶与轻微年代感，不得出现模型粘贴感。

硬性约束：不得移动、镜像、合并、删减或新增建筑；保持主要屋脊、院墙、门洞、开间节奏与亭台轮廓；树木不得遮挡主要建筑证据；去除 SU 坐标轴、白底和全部语义标注。
避免：照片感、3D 渲染感、游戏概念图、动漫、浮世绘、纯泼墨、西方水彩、强透视、广角、体积光、投影、过饱和、现代蓝色水面、纯 CAD 线、塑料材质、满幅同等清晰、重度仿旧、现代构件、船、人、牌匾、题诗、印章、锦边、水印和任何文字。
```

若第一次生成出现结构漂移，第二轮只使用以下类型的单一修正：

```text
只修正建筑结构：恢复 <具体偏差>，严格对齐原 SU 图的 <对应屋脊/墙线/亭台/廊道>。保持当前山水风格、综合色阶、画幅和其他区域完全不变；不要新增任何物体或文字。
```

若结构正确但仍像现代插画，只做以下质感校准：

```text
只校准为《圆明园四十景图》原作画心质感：降低整体饱和度和数字锐度；把纯白背景统一为浅米黄旧绢；把机械 CAD 线转为细而略有手工变化的深褐墨线；补足平行瓦线、圆浑层叠山皴、点叶树冠、近乎绢底留白的水面、淡青灰远山和均匀无投影光线。所有建筑位置、轮廓、屋顶、山水边界和构图完全不变；不添加题诗、印章、边框或任何文字。
```

## B版建筑历史校色

先完成并保存 A 版，再将 A 版作为唯一编辑目标执行以下提示。可附加 1–2 张原作建筑参考，但必须声明它们只提供色彩依据。

```text
生成与 A 版配对的 B｜历史校色版。本轮只修改建筑及其院墙、台基的综合色，不改变任何线条、结构、细节、地形或山水内容。

将现代建模感较强的建筑颜色校准为《圆明园四十景图》原作画心设色：
- 鲜红柱、门框和檐下构件改为低饱和、偏赭偏褐的旧朱砂/朱红，保留红色识别度但不鲜亮；
- 鲜青、亮绿和彩画改为极克制的灰石青、灰石绿和黛青绿，只作局部点色；
- 近黑屋瓦改为低对比灰青、灰褐和墨灰，完整保留平行瓦线与屋面层次；
- 墙面、院墙与台基改为吸收浅米黄绢底的温灰白、浅灰褐，避免现代水泥灰；
- 木门窗使用沉静赭红、深木褐与少量灰青绿；建筑整体降低饱和度和明度对比，但仍比远山略清楚。

必须与 A 版保持相同画幅、构图、相机视角、建筑轮廓、屋顶、开间、柱列、院墙、台地、地形、树林、道路、远山、留白与遮挡关系。不得重新生成形体，不得整体重新着色，山水与绢本底色保持不变。

避免现代鲜红、荧光绿、宝蓝、纯黑屋瓦、塑料彩画、褪色到无法辨认，以及任何新增对象、题诗、印章、边框、水印或文字。
```
