# 原作参考选择

内置参考位于 `assets/reference-plates/`，均从项目 `圆明园四十景/` 的原作高清图中裁取画心并缩放，仅用于风格锚定。一次生成选 2–3 张，不要全部输入。

## 参考画页

- `01-architecture-courtyard.jpg`：建筑密集、轴线和院落清楚。用于大型院落、主体宫殿和界画线性。
- `05-wooded-garden.jpg`：林木围合、池岸、楼阁与园墙。用于树木密集的庭园。
- `08-waterfront-pavilion.jpg`：大面积水面、临水建筑、山谷和留白。用于湖岸、码头、楼阁。
- `13-water-islands.jpg`：水岛分隔、远山、岸线和疏朗建筑。用于多个分散建筑组团或水体主导场景。
- `14-mountain-valley.jpg`：连续高山、坡地串联和多层建筑。用于山体主导、高差较大的场景。
- `21-rural-waterside.jpg`：疏林、田地、缓坡与水岸。用于平地、农田或开敞郊野场景。

## 选择规则

总是先选一张与 SU 总体空间最接近的构图参考，再补一张建筑或环境细节参考：

- 密集院落：`01` + `05`；若有高山再加 `14`。
- 临水建筑：`08` + `13`；林木较多再加 `05`。
- 山地园林：`14` + `05`；有开阔水面再加 `08`。
- 分散组团：`13` + `21`；主体院落复杂再加 `01`。
- 开阔平地：`21` + `01`；有水岛再加 `13`。

输入提示中逐张说明用途，强调只学习共同风格，不复制其构图或对象。参考图上的印章、装裱边缘与旧斑仅用于理解历史载体，默认输出中不得出现。
